# Fullstack Open — Parts 1 & 2 (Completed)

This repository contains my completed **Part 1** and **Part 2** of the [Fullstack Open](https://fullstackopen.com/) course by the University of Helsinki.

## Part 1: Introduction to React
The exercises cover the fundamentals of React, including:
- Component structure and props  
- State management with `useState`  
- Event handling  
- Rendering dynamic content

## Part 2: Communicating with Server
The exercises expand on React and introduce:
- Rendering collections and forms
- Fetching data from a server
- Adding data to a server
- Styling React apps

## 🚀 How to Run the Project
Clone the repository and run it locally:
```bash
git clone <this-repo-url>
cd <your-repo-folder>
npm install
npm run dev
```

## 💡 Additional Work

I also added custom **visual elements and styling** to refresh and improve my front-end design skills.  
This includes small UI experiments and aesthetic enhancements beyond the original exercises.

To enable the visuals, install the following dependencies:

```bash
npm install ogl
npm install gsap
```
Then open the link shown in your terminal (usually http://localhost:5173)
